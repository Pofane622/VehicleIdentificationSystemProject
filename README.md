# Vehicle Identification System

## Overview
A comprehensive vehicle management system built with JavaFX and PostgreSQL for OOP2 assignment.

## Features
- Admin Module - Give/deny user access
- Vehicle Management - Register and track vehicles
- Customer Management - Store customer information
- Workshop Module - Track service history
- Customer Queries - Submit and respond to questions
- Insurance Module - Manage policies and claims
- Police Module - File reports and track violations
- Dynamic Reports Dashboard - Real-time statistics

## Technologies
- Java 17
- JavaFX
- PostgreSQL
- JDBC
- Maven
- CSS

## How to Run

### Prerequisites
- PostgreSQL installed (port 5432)
- Java 17 or higher
- Maven

### Database Setup
1. Create database: `vehicle_identification_system`
2. Run the SQL schema to create tables

### Run Application
1. Open project in IntelliJ
2. Update database password in `DatabaseConnection.java`
3. Run `Launcher.java`
